{% load humanize %} {% comment %} Storage banner. Same contract as _power_warning.html: rendered on every page from the shared navbar context, never dismissible, plain language only. The mechanism (ext4 counters, the write check, eMMC wear registers) is on System Info behind a disclosure. Six states rather than the power banner's two, because unlike a brown-out the failures here are not one thing at different intensities. "It's full", "it went read-only" and "it's wearing out" have different causes and different fixes, and an operator told the wrong one goes and buys the wrong thing. The state is chosen server-side (page_context._storage_kind); this template renders it. media_noun rather than a hardcoded "memory card": most of the fleet boots from an SD card, the compute modules from soldered eMMC, and x86 from an SSD. What to do

    {% if storage_warning.kind == 'full' %} {% comment %} A full drive is the one state here that isn't a hardware problem, so its advice shares nothing with the rest. Leading on deleting content keeps an operator from buying hardware they don't need. {% endcomment %}
  • Remove content you no longer need from the Schedule page. Deleting an asset frees its file straight away.
  • Videos are almost always what filled it. One long, high-quality video can take more space than a whole playlist of images.
  • System Info shows how much space is left, so you can check before adding anything back.
    • {% else %} {% if storage_warning.replaceable %}
  • Replace the {{ storage_warning.media_noun }}. Storage wears out from ordinary use, and once it has started failing it doesn't come back. This is the fix, and doing it now is much less work than doing it after the player stops starting up.
    • {% else %}
  • Plan to replace this player. Its storage is soldered to the board, so there's nothing to swap out. Getting a replacement ready now avoids an unplanned outage later.
    • {% endif %}
  • Take a backup first, from Settings, while it can still be read. If the backup itself fails, this is further gone than it looks and the replacement is urgent.
    • {% if storage_warning.media_kind == 'sd' %}
  • Buy a card rated A1 or A2 from a brand you recognise. Cheap cards and counterfeits are the usual cause of this, and a signage player writes far more than a card sold for a camera expects.
    • {% endif %} {% if not power_warning %} {% comment %} Omitted when the power banner is already on screen directly above saying the same thing at greater length. Repeating it would read as filler and cost this list the attention its first item needs. {% endcomment %}
  • Check the power supply as well. A supply that can't hold its voltage is one of the main things that damages storage, and a replacement will go the same way if that's the cause.
