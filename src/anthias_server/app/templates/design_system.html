{# ===================== Type ===================== #}

Type

Nine steps, on Tailwind's own names and values, so text-sm in markup and var(--text-sm) in CSS mean the same number. This replaced 27 ad-hoc sizes, ten of which sat inside a single 0.2rem band. Line heights are tightened throughout for a dense operator UI.

{# ===================== Spacing ===================== #}

A single 0.25rem base. Tailwind's p-4 / gap-2 and any calc(var(--spacing) * n) in CSS both derive from it, so the two scales that used to be numerically coincidental but unlinked are now one scale.

{# ===================== Layering ===================== #}

Layering

One ordered scale, replacing 1040/1050/1060/1080/1090/1100 scattered across the stylesheet and three inline style attributes. Two constraints are encoded here: Leaflet's internal panes run 400-1000 in their own stacking context so the map must stay below the modal, and Flatpickr opens from inside modals so its calendar has to clear the nested tier.

{# ===================== Breakpoints ===================== #}

Breakpoints

Written once, in @theme. Markup uses lg: and CSS that Tailwind compiles (base.css, theme-dark.css) uses @variant lg; both resolve here. The component sheet is different: _styles.scss is compiled by sass and never passes through Tailwind, so @variant is not available to it and it writes plain media queries against these same pixel values. A few component rules there use off-scale widths (420, 540, 720, 880, 1100) for the case where a component runs out of room rather than the page.

{# ===================== Surfaces ===================== #}

Surfaces

.surface declares a context, not just a background: it exposes --surface-* custom properties that children read, so .surface--active flips every descendant's contrast without a single descendant selector. This is the pattern that makes theming nearly free.
